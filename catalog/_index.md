# 工具目录总览

内容按三个维度组织。具体工具放在各维度下的分组目录中；新增条目请复制 `templates/tool/`。

| 维度 | 路径 | 说明 |
|------|------|------|
| 编程语言 | [languages/](./languages/) | 语言生态内的包管理、测试、格式化、构建等 |
| 常见框架 | [frameworks/](./frameworks/) | 框架官方工具链与强绑定周边 |
| 应用领域 | [domains/](./domains/) | 跨语言场景：web、devops、data、ai-ml 等 |

当前多为空分组占位，尚无完整工具正文。在 GitHub 上直接浏览本树即可；架构说明见 [`docs/project-architecture.md`](../docs/project-architecture.md)。
