# Languages（编程语言）

按语言 slug 分子目录（如 `python/`、`typescript/`、`go/`），其下再放具体工具包。

## 已登记分组

| 分组 | 路径 | 说明 |
|------|------|------|
| Python | [python/](./python/) | Python 生态工具（占位） |
| TypeScript | [typescript/](./typescript/) | TypeScript / JS 工具链（占位） |
| Go | [go/](./go/) | Go 工具链（占位） |

新增语言分组时：创建目录、添加本表一行，并复制 `templates/tool/` 放入首个工具（可为 stub）。
