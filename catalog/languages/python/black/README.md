# Black

> status: draft

## 是什么

Black 是意见明确的 Python 代码格式化工具（「不妥协」风格）：减少风格争论，适合团队统一格式。许多项目仍以 Black 为 CI 格式化标准；新项目也可评估 [ruff](../ruff/) formatter。

## 何时使用

- 适用：已有 Black 配置的代码库；只需稳定、可预测的格式化。
- 不太适合：希望 lint+format 单工具且追求极致速度——可看 [ruff](../ruff/)。
