# pytest

> status: draft

## 是什么

pytest 是 Python 最常用的测试框架之一：简洁断言、丰富的插件生态（覆盖率、并行、参数化等），适合单元测试与中小型集成测试。

## 何时使用

- 适用：库与服务的自动化测试；需要可读失败信息与插件扩展。
- 不太适合：强制 unittest 风格且无迁移计划的遗留仓库——仍可渐进引入 pytest 运行 unittest。
