# IPython

> status: draft

## 是什么

IPython 是增强型交互式 Python shell：更好的补全、对象内省、魔法命令（`%timeit` 等），也是 Jupyter 内核的基础组件之一。

## 何时使用

- 适用：终端里快速探索 API、调试数据变换、做微基准。
- 不太适合：需要可分享的富文档叙事——改用 [jupyter](../jupyter/)。
