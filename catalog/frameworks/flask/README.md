# Flask

> status: draft

## 是什么

Flask 是轻量 Python Web 微框架：核心小、扩展多，路由与视图直观，适合 API、小站点与需要高度自定义架构的服务。

## 何时使用

- 适用：想自己选型 ORM/验证/结构；快速搭原型或小型服务。
- 不太适合：希望开箱即用 Admin/ORM/用户体系——可看 [Django](../django/)；高性能异步 API 可看 [FastAPI](../fastapi/)。
