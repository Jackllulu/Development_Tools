# FastAPI

> status: draft

## 是什么

FastAPI 是现代、高性能的 Python API 框架：基于类型注解生成校验与 OpenAPI 文档，原生支持 async，常与 Uvicorn / Starlette / Pydantic 搭配。

## 何时使用

- 适用：JSON API、微服务、需要自动文档与数据校验的服务。
- 不太适合：以服务端渲染 HTML 为主的大型 CMS——可看 [Django](../django/)；极简同步脚本 API 有时 [Flask](../flask/) 更直观。
