# Django

> status: draft

## 是什么

Django 是全功能 Python Web 框架（「batteries included」）：ORM、Admin、表单、认证、模板与迁移开箱即用，适合中大型站点与后台管理系统。

## 何时使用

- 适用：需要完整 MVC/MTV、后台 Admin、成熟约定与安全默认的 Web 应用。
- 不太适合：只要轻量 API、极简依赖——可看 [Flask](../flask/) 或 [FastAPI](../fastapi/)。
